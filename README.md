A forecaster for GTA VI's launch-day Twitch viewers, hour by hour. Peak-and-shape model in log space: it learns the day's peak and hourly shape from 38 past big game launches and forecasts 5 quantiles for hours 2–24. Leave-one-out pinball loss 0.41 vs 0.93 for the persistence baseline.

## Run it

```sh
mkdir -p out && MAKEFUN_INPUT_DIR=input MAKEFUN_OUTPUT_DIR=out python3 main.py
```
